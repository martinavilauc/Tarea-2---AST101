# El proyecto:
Nuestro proyecto consiste en una pagina de un mapa en vivo (aun por discutir si en 2D o en 3D) que utiliza datos en vivo de https://ssd.jpl.nasa.gov/horizons/#web para conseguir coordenadas de cuerpos celestes del sistema solar (entre otras cosas).
# Metodologia:
Usaremos la plataforma Vercel para la pagina, y github para desarrollar el codigo, usaremos python para la programacion.
